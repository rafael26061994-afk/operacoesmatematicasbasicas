# AJUSTES V27 — SAIR DO PERFIL

## O que mudou
- Adicionada a ação **Sair do perfil atual** na tela de perfis.
- A opção só aparece quando existe um perfil local ativo (não visitante).
- Ao sair do perfil, o app:
  - encerra a conta online vinculada neste navegador;
  - limpa o perfil ativo local;
  - volta para o modo visitante;
  - exige novo acesso por PIN para reentrar no perfil.

## Objetivo
Impedir que outro usuário no mesmo dispositivo continue usando o perfil que já estava aberto.
